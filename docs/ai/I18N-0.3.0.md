# Lumen 0.3.0 — user-facing strings

Rules: keys are stable; {placeholders} must be identical in all languages; avoid plural forms by using "label: {count}" patterns; quote marks around names avoid grammatical case problems. Web: `src/lib/i18n.ts`. Android: `res/values/strings.xml`, `values-ru`, `values-be` (dots in a key become underscores; placeholders become positional `%1$s`, in the same order). A parity test must fail on any missing key, empty value or placeholder mismatch.
